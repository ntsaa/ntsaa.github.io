Master NTSAA in a Few Steps

Screenshot and editing tool inspired by LightShot, featuring smart text recognition and Google-powered translation.

1. Open the application

  • Download and run NTSAA_..._Bundle.exe to extract (defaults to Portable mode, no Administrator privileges required).
  • Once completed, NTSAA will automatically launch and sit ready in the System Tray (bottom-right corner of your screen).
  • Press PrtScn (Print Screen) anytime to start selecting a screen capture area.
Note:
  • If a blue warning screen appears (SmartScreen), select More info ➔ Run anyway to continue.
  • The Bundle installer will automatically install .NET 8 if not already present on your system.

2. Convert image to text

  • Select the area of the image you want to recognize.
  • Press Ctrl+T or click the Text AI icon (boxed in red) on the toolbar.

3. Use drawing tools

  • Select the area of the image you want to edit.
  • Use drawing or text tools from the toolbar (usually located on the right side of the capture area).
  • Hold Shift while drawing to create perfect squares/circles or snap line/arrow angles (0°, 30°, 45°, 60°, 90°).
  • Hold Alt to select any drawn shape to move, resize, or right-click to convert types.

4. Keyboard Shortcuts

💡 All shortcuts and hotkeys listed below are defaults and can be fully customized in Settings.

🌐 Global Hotkeys
  • PrtScn - Start screen capture
  • Alt+Shift+C - Pick screen color (Color Picker)
  • Alt+Shift+H - Open capture history (History)
💡 Basic (On Canvas)
  • Ctrl+T - Convert image to text
  • Ctrl+C - Copy image
  • Ctrl+S - Save image
  • Ctrl+X - Close
🖱️ General Controls
  • Double-click - Full-screen selection
  • Scroll - Adjust stroke thickness
  • Shift (drawing) - Constrain proportions (Square, Circle) or angles (0°, 30°, 45°, 60°, 90°)
  • Alt (hold) - Select and edit drawn items
  • Ctrl+D - Duplicate selected shape
✏️ Drawing Tools
  • P Pen
  • T Text
  • L Line
  • N Number
  • A Arrow
  • M Marker
  • R Rectangle
  • B Blur
  • E Ellipse
  • Tab Switch tool
🎨 Colors
  • 1-9 - Quick select AOE team colors
    (1-Blue, 2-Red, 3-Yellow, 4-Brown, 5-Orange, 6-Green, 7-Gray, 8-Cyan, 9-Violet* - app theme)
  • ` - Toggle previous color
  • Ctrl+` - Choose color
💡 For text items, combine with Ctrl
💬 Confirm & Delete
  • Enter / Esc - Complete drawing or shape resizing
  • Delete / Backspace - Delete selected shape
💡 For text items, combine with Ctrl
📐 Move & Resize
  • ↑ / ↓ / ← / → - Move selected area or shape
💡 Hold Shift to resize in key direction
🔍 Display Options
  • F1 - Toggle shortcut hints
  • F2 - Show/hide UIA text
  • F3 - Copy UIA text
  • F4 - Toggle Text Box border; toggle fill
⚙️ Stroke Adjustments
  • F5 - Reset stroke to default
  • F6 / F7 - Decrease / Increase thickness
  • F8 - Toggle stroke (Square ↔ Round)
