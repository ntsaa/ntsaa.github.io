Master NTSAA in a Few Steps

Screenshot and editing tool inspired by LightShot, featuring smart text recognition and Google-powered translation.

1. Open the application

  • Download and run NTSAA_..._Bundle.exe to extract (defaults to Portable mode, no Administrator privileges required).
  • Once completed, NTSAA will automatically launch and sit ready in the System Tray (bottom-right corner of your screen).
Note:
  • If a blue warning screen appears (SmartScreen), select More info ➔ Run anyway to continue.
  • The Bundle installer will automatically install .NET 8 if not already present on your system.

2. Convert image to text

  • Select the area of the image you want to recognize.
  • Press Ctrl+T or click the Text AI icon (boxed in red) on the toolbar.

3. Use drawing tools

  • Select the area of the image you want to edit.
  • Use drawing or text tools from the toolbar (usually located on the right side of the capture area).
  • Hold Alt to select any drawn shape to move, resize, or right-click to convert types.

4. Keyboard Shortcuts

💡 Basic
  • Ctrl+T - Convert image to text
  • Ctrl+C - Copy image
  • Ctrl+S - Save image
  • Ctrl+X - Close
🖱️ Controls and general actions
  • Double-click mouse - Toggle full-screen selection mode
  • Scroll mouse - Increase/decrease stroke thickness
  • Hold Shift - Constrain proportions (square, circle) or line angle
  • Hold Alt - Select and edit (move, resize) previously drawn items
  • Ctrl+D - Duplicate selected drawn shape
  • Alt+Shift+H - Open Capture History / Workspace
🎨 Colors
  • R / G / B / Y - Select color Red / Green / Blue / Yellow
  • ` - Revert to the previous color
  • Ctrl+7 - Select color
✏️ Drawing tools
  • 1-9 - Select drawing tools (except 7, use Ctrl+7 to select color)
  • Tab / Shift+Tab - Switch between drawing tools
📐 Move or resize
  • ↑ / ↓ / ← / → - Move the selected area up, down, left, or right
  • Hold Shift - Resize the selected area in the corresponding direction
💬 Text & completion
  • Enter - Complete when the shape is in resizable mode
  • Ctrl+Enter - Complete when typing text
🔍 Display options
  • F1 - Show/hide shortcut hints
  • F2 - Show/hide UIA text
  • F3 - Copy UIA text
  • F4 - Toggle Text Box border/background; toggle shape fill (rectangle/ellipse)
⚙️ Stroke adjustments
  • F5 - Reset stroke thickness to default
  • F6 - Decrease stroke thickness
  • F7 - Increase stroke thickness
  • F8 - Toggle stroke shape (Square ↔ Round)
